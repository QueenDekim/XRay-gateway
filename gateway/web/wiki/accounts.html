Пользователи и безопасность

Пароли содержат от 8 до 1024 символов. Обычный пользователь меняет свою учётную запись, но не общие настройки, профили, списки или подключение RouterOS.

Аватар передаётся в base64, допускаются PNG, JPEG и WebP до 2 МБ. Пустая строка удаляет аватар. Секрет TOTP возвращается только при настройке; коды восстановления — при создании.

POST /api/account/profile

user

Меняет display_name и preferences своей учётной записи.

Запрос

{
  "display_name": "Operator",
  "preferences": {
    "language": "en",
    "design": "titan",
    "colorScheme": "dark"
  }
}

POST /api/account/avatar

user

Сохраняет или удаляет свой аватар.

Запрос

{
  "image": "<base64 image bytes>"
}

POST /api/password

user

Меняет пароль после проверки текущего.

Запрос

{
  "current_password": "old-password",
  "password": "new-password"
}

POST /api/account/2fa/setup

user

Создаёт временный секрет и URI настройки после проверки пароля.

Запрос

{
  "password": "current-password"
}

GET /api/account/2fa/qr

user

PNG QR-код незавершённой настройки.

POST /api/account/2fa/enable

user

Включает TOTP и выдаёт коды восстановления.

Запрос

{
  "code": "123456"
}

POST /api/account/2fa/disable

user

Отключает TOTP после проверки пароля и кода.

Запрос

{
  "password": "current-password",
  "code": "123456"
}

POST /api/account/2fa/recovery

user

Пересоздаёт одноразовые коды восстановления.

Запрос

{
  "password": "current-password",
  "code": "123456"
}

POST /api/users/add

admin

Создаёт пользователя с role admin или operator.

Запрос

{
  "username": "reader",
  "password": "example-password",
  "role": "operator"
}

POST /api/users/edit

admin

Меняет пользователя по id и revision. Пустой пароль сохраняет прежний.

Запрос

{
  "id": "user-id",
  "revision": 1,
  "username": "reader",
  "password": "",
  "role": "operator"
}

POST /api/users/delete

admin

Удаляет пользователя. Панель защищает последнего администратора и запрещает самоудаление.

Запрос

{
  "id": "user-id",
  "revision": 1
}
