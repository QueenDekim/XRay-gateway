Вход и сессии

Для интеграций используйте API-токены. Следующие методы обслуживают вход и выход веб-панели; сессионные POST-запросы требуют X-CSRF-Token из GET /api/state.

Сессия действует 12 часов. Панель хранит сессии зашифрованными и проверяет ревизию учётной записи при каждом обращении. Смена пароля и прав отзывает старые сессии.

Если у пользователя включена 2FA, первый запрос возвращает challenge без cookie. Передайте challenge и code во второй запрос. Незавершённый вход истекает через три минуты.

POST /api/login

public

Проверка логина и пароля. При успехе без 2FA устанавливает cookie.

Запрос

{
  "username": "admin",
  "password": "example-password"
}

Ответ

{
  "requires_2fa": true,
  "challenge": "temporary-challenge"
}

POST /api/login/2fa

public

Завершает вход по одноразовому коду или коду восстановления.

Запрос

{
  "challenge": "temporary-challenge",
  "code": "123456"
}

Ответ

{
  "ok": true
}

POST /api/logout

user

Отзывает текущую сессию и закрывает её терминал RouterOS.

Запрос

{}

Ответ

{
  "ok": true
}
