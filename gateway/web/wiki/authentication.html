Авторизация Bearer

Создайте API-токен через настройки пользователя → API и передавайте Authorization: Bearer <token> в каждом запросе. Cookie и CSRF для Bearer-запросов не требуются. Используйте HTTPS.

API не принимает логин и пароль для входа. Не передавайте токен в URL. GET /api/version доступен без авторизации. Для интеграций используйте Bearer; управление токенами выполняйте после входа в веб-панель.

По умолчанию допускается 300 проверяемых Bearer-запросов в минуту с одного адреса. После пяти неверных токенов за 15 минут действуют блокировки на 1, 5, 15, 60 минут, затем сутки. HTTP 429 содержит retry_after и заголовок Retry-After в секундах. Не повторяйте запрос до истечения этого срока.
