IP-списки и домены

Список принимает IPv4, IPv6, CIDR и доменные имена. Разделяйте записи пробелами, запятыми, точками с запятой или переводами строк. Панель удаляет дубликаты и не разрешает домены заранее в IP.

Редактирование и удаление используют version конкретного списка. Удаление сначала очищает принадлежащие списку ресурсы RouterOS; при ошибке сохраняет запись панели.

POST /api/ip-lists/add

admin

Создаёт список и возвращает list.

Запрос

{
  "name": "Services",
  "addresses": "example.org\n1.1.1.1\n2606:4700:4700::1111"
}

POST /api/ip-lists/edit

admin

Обновляет имя и содержимое своего списка.

Запрос

{
  "id": "list_0123456789ab",
  "version": 1,
  "name": "Services",
  "addresses": "example.org\n1.1.1.1"
}

POST /api/ip-lists/delete

admin

Запускает очистку RouterOS и удаление списка. Возвращает 202 с id задания; читайте журнал RouterOS.

Запрос

{
  "id": "list_0123456789ab",
  "version": 1
}

Ответ

{
  "id": "job-id"
}
