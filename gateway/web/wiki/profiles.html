Профили и подписки

Каждый профиль имеет собственный приоритет от 1 до 1000. Меньшее число имеет преимущество среди доступных включённых профилей. Изменение конфигурации проверяет её и перезапускает Xray.

Для подписки сначала получите кандидатов. Токен выбора связан с сессией и действует пять минут. При добавлении можно выбрать несколько профилей, при замене — один. Повторный импорт обновляет совпавшие записи своей группы.

POST /api/profiles/preview

admin

Загружает VLESS-подписку и возвращает token, profiles, skipped и group. В profiles указаны id кандидата, имя, адрес, порт, транспорт и защита.

Запрос

{
  "uri": "https://example.org/subscription/token"
}

POST /api/profiles/add

admin

Добавляет профиль. Для подписки передайте token, выбранные ID и отдельные имена и приоритеты. revision берите из /api/state.

Запрос

{
  "revision": 1,
  "uri": "https://example.org/subscription/token",
  "enabled": true,
  "name": "",
  "priority": 10,
  "subscription_token": "selection-token",
  "subscription_profiles": [
    "candidate-id"
  ],
  "subscription_name": "My subscription",
  "subscription_options": {
    "candidate-id": {
      "name": "Primary",
      "priority": 10
    }
  }
}

Ответ

{
  "ok": true
}

POST /api/profiles/edit

admin

Принимает id профиля и текущую revision. Пустой uri сохраняет подключение; name, priority и enabled редактируются отдельно.

Запрос

{
  "id": "primary",
  "revision": 2,
  "name": "Primary",
  "priority": 5,
  "enabled": true,
  "uri": ""
}

Ответ

{
  "ok": true
}

POST /api/profiles/delete

admin

Удаляет профиль. Нужны id и revision.

Запрос

{
  "id": "primary",
  "revision": 2
}

Ответ

{
  "ok": true
}

POST /api/profiles/reset-checks

admin

Сбрасывает только число проверок и успешных проверок. Счётчики трафика сохраняются.

Запрос

{}

Ответ

{
  "ok": true
}
