RouterOS и задания

Настройте SSH-доступ и закрепите отпечаток ключа хоста. Секреты сохраняются зашифрованными. Пустые поля секрета при сохранении того же подключения сохраняют существующие значения.

GET /api/routeros/config

admin

Параметры SSH без пароля и приватного ключа; configured и passphrase_set указывают сохранённое состояние.

POST /api/routeros/host-key

admin

Получает отпечаток для проверки администратором.

Запрос

{
  "host": "192.168.50.1",
  "port": 22
}

POST /api/routeros/config

admin

Проверяет и сохраняет SSH-подключение. Для ключа используйте private_key и необязательную passphrase, для пароля — password.

Запрос

{
  "host": "192.168.50.1",
  "port": 22,
  "username": "xray-panel",
  "auth": "key",
  "fingerprint": "SHA256:verified-host-key",
  "private_key": "<OpenSSH private key>",
  "passphrase": ""
}

POST /api/routeros

user

Генерирует скрипт без выполнения. Можно указать list_id или destinations, source, interface и local_networks.

Запрос

{
  "list_id": "list_0123456789ab",
  "source": "192.168.50.0/24",
  "interface": "bridge",
  "local_networks": "192.168.50.0/24"
}

POST /api/routeros/apply

admin

Устанавливает или заменяет список. Возвращает 202 с id задания.

Запрос

{
  "id": "list_0123456789ab",
  "version": 1
}

Ответ

{
  "id": "job-id"
}

GET /api/routeros/jobs

admin

Список недавних операций.

GET /api/routeros/jobs/{id}?cursor=0

admin

Возвращает status, logs и следующий cursor. Состояния: queued, running, done, error.
