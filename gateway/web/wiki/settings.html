Настройки панели

GET /api/state содержит settings и их revision. Меняйте только нужные поля и передавайте актуальную ревизию. Настройки маршрута используются при операциях RouterOS; пользовательские значения сохраняются между перезапусками.

POST /api/settings

admin

Настраивает gateway, host, source, interface, local_networks, probe_url, check_interval, fail_threshold и recover_threshold.

Запрос

{
  "revision": 1,
  "source": "192.168.50.0/24",
  "interface": "bridge",
  "probe_url": "https://www.gstatic.com/generate_204",
  "check_interval": 10,
  "fail_threshold": 3,
  "recover_threshold": 2
}
