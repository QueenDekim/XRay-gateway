Начало работы

Все пути API относятся к адресу панели. Запросы и ответы используют JSON.

После входа сохраняйте cookie xray_session. Получите csrf через GET /api/state и передавайте его в X-CSRF-Token для защищённых POST-запросов.

Ошибки возвращают поле error. Accept-Language: en включает английский язык; по умолчанию используется русский. Коды 400, 401, 403, 429 и 503 обозначают неверные данные, отсутствие сессии, запрет доступа, ограничение частоты и недоступность операции.

GET /api/version

public

Версия, полный SHA исходников и ссылка на тег. Вход не требуется.

Ответ

{
  "base_version": "1.9.0",
  "version": "1.9.0-abcdef0",
  "revision": "abcdef0123456789abcdef0123456789abcdef0123",
  "tag": "1.9.0-abcdef0",
  "url": "https://github.com/QueenDekim/XRay-gateway/tree/1.9.0-abcdef0"
}

GET /api/state

user

Состояние шлюза, профили, списки, статистика, текущий пользователь и CSRF. Поле users доступно администратору. Пароли и VLESS-ключи не возвращаются.
