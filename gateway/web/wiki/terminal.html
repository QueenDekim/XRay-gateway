Терминал RouterOS

Терминал использует SSH PTY и связан с пользователем и сессией. Сырой вывод передаётся в base64. Простой завершает соединение через пять минут; максимальная длительность — час.

POST /api/routeros/terminal/open

admin

Открывает терминал и возвращает id.

Запрос

{
  "cols": 100,
  "rows": 30
}

Ответ

{
  "id": "terminal-id"
}

GET /api/routeros/terminal/{id}?cursor=0

admin

Читает data, cursor и closed. data нужно декодировать из base64.

POST /api/routeros/terminal/input

admin

Отправляет текст, управляющие символы и ответы терминала.

Запрос

{
  "id": "terminal-id",
  "data": "/system identity print\r"
}

POST /api/routeros/terminal/resize

admin

Изменяет размер PTY.

Запрос

{
  "id": "terminal-id",
  "cols": 120,
  "rows": 36
}

POST /api/routeros/terminal/close

admin

Закрывает соединение своей сессии.

Запрос

{
  "id": "terminal-id"
}
