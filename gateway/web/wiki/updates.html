Обновления

Проверка выбирает более новую версию с опубликованными образами Gateway и Updater. Установка использует закреплённые digest, сохраняет данные, пересоздаёт Compose-сервисы и выполняет откат при неуспешной проверке.

Автоустановка по умолчанию отключена, периодическая проверка включена. Настройте отдельную службу updater; Docker socket доступен только ей, а не панели. Во время установки операции записи возвращают 503.

GET /api/updates

user

Текущая и доступная версии, время проверки, подключение службы и задание. Настройки и подробный журнал доступны администратору.

POST /api/updates/check

admin

Запускает проверку в фоне и возвращает 202. Повторные проверки ограничены одной в минуту.

Запрос

{}

POST /api/updates/settings

admin

Период проверки: от 1 до 168 часов. auto_install управляет автоматической установкой.

Запрос

{
  "check_interval_hours": 6,
  "auto_install": false
}

POST /api/updates/install

admin

Устанавливает доступный tag из результата проверки. Возвращает 202 с id задания; читайте /api/updates для хода операции.

Запрос

{
  "tag": "1.9.0-abcdef0"
}

Ответ

{
  "id": "update-job-id"
}
